# Libro de versiones — Don Pepito 🍹

Cada versión publicada lleva su sello visible en el pie de la app y de la web
(p. ej. «v12ago-6»). Todas quedan guardadas para siempre: para **volver a una
versión anterior**, pídeselo a Claude («vuelve a la v12ago-5») o en el Mac:

```bash
git checkout vXXXX -- web/   # recupera la web de esa versión
firebase deploy               # y publícala
```

**Norma de trabajo:** ninguna versión nueva se fusiona ni se publica sin
enseñarla antes (capturas o vista previa) y sin el visto bueno del dueño.
