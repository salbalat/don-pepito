# Instrucciones del proyecto

- Trabajar siempre dentro de esta carpeta.
- Leer `README.md`, `ESTADO.md` y `ARCHITECTURE.md` antes de cambiar código o documentación.
- Preservar cambios existentes y no usar operaciones destructivas sin autorización explícita.
- No leer, copiar ni mostrar secretos, tokens, credenciales o datos personales innecesarios.
- Validar con las pruebas o verificaciones propias del proyecto.
- Registrar cambios remotos de forma append-only en `MOBILE_CODEX_LOG.md`.
- No reabrir decisiones cerradas de PPD, Factoría o MEISSON desde este proyecto.
- No mover datos, artefactos o rutas operativas sin comprobar despliegue, copias y rollback.
